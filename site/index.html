Fast is easy. Trustworthy is the point.

AI that ships code needs rules it can't talk its way around. Fixline enforces four.

01

No fix without proof

The bug must be reproduced by a failing test before anyone touches the code.

02

The proof can't be edited

Once confirmed, the test is locked. A fix that changes it is rejected automatically.

03

A second AI reviews

Codex reviews what Claude Code wrote. In one run it caught a regression and sent the fix back.

04

A person approves

Only the engineering lead can press Approve. Switch enforces it, not a promise in a prompt.

Support finally hears how it ended

Every ticket closes with a plain-English explanation for the support person and a ready-to-send reply for the customer. Repeat complaints don't become tickets at all: triage answers them from the team's known-issues document in seconds.

Powered by Switch

Agents that work like teammates

Switch turns a chat channel into a shared workspace for people and AI agents. Fixline uses it for everything that makes the crew a team:

  • RolesWork goes to "whoever reviews", so you can swap an agent without changing the process
  • One thread per issueThe conversation is the ticket; anyone can read exactly what happened
  • Shared documentsKnown issues and a fix ledger every agent and person can see
  • Approval buttonsA recorded yes or no in the chat your team already uses

Running in three commands

$ make up      # Switch + Mattermost in Docker
$ make setup   # 5 agents, the room, roles and docs (~30 s)
$ make crew    # the crew goes to work

Needs Docker, Node 20+, and the Claude Code and Codex CLIs you already use.

Questions

Do I need Slack or a company workspace?

No. Mattermost comes bundled, so everything runs on your laptop. Switch also connects to Slack, Teams, Discord and Telegram; Fixline was tested on Mattermost.

What if the AI gets the fix wrong?

It has to pass the locked test and the whole test suite, then a review by a different model. If your lead still isn't happy, they press Decline and nothing is merged.

Can support accidentally ship code?

No. Only the engineering lead's approval counts. In every test run support tried to approve first, and Switch ignored it.

Where does my code go?

To Anthropic and OpenAI through their own CLIs, exactly as when you use them in a terminal. Switch, the chat and git all run locally.

What does it cost?

Fixline and Switch are free and open source. You use your existing Claude Code and Codex subscriptions.
